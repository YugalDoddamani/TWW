The Wellness Workshop
Programs Page

A concise review of the wireframe improvements made to the Programs page, with a focus on clearer structure, balanced alignment, responsive behaviour and a consistent experience across the wider website.

Concept 01 · Version 03 Wireframe stage Existing brand retained

Purpose of this iteration

The goal was to improve the layout and interaction details without replacing the website’s established visual identity. The page remains a wireframe: program content, imagery and pricing are intentionally represented with placeholders until they are confirmed.

What has been improved

01

Balanced header alignment

The logo has moved from the centre to the left, aligned with the main content container. Navigation sits centrally and the contact action remains on the right. This distributes visual weight more evenly and creates a clearer reading path.

02

Cleaner mobile navigation

The mobile header keeps the logo on the left and groups the actions on the right. The hamburger icon transitions into a close icon, while the menu opens as a clear, spaced panel that is easier to scan and tap.

03

More consistent spacing

Alignment, gaps and component spacing are treated more systematically. This gives the header, program cards, calls to action and supporting sections a more cohesive rhythm instead of making each element feel separate.

04

Subtle depth and button feedback

Light shadows help key buttons and the mobile menu stand apart from the background. Hover and press states use small lifts, shadow changes and restrained motion to make interactions feel responsive without becoming distracting.

05

Micro-interactions across components

Navigation links, dropdowns, cards and buttons receive consistent feedback. The existing cursor treatment remains a desktop enhancement rather than a requirement for using the page.

06

Responsive and accessible behaviour

The layout adapts for desktop and mobile widths. Keyboard interaction, visible focus, Escape-to-close behaviour and reduced-motion preferences are considered so the experience is not dependent on a mouse or animation.

What stays consistent

The existing brand palette, logo asset, typography direction, familiar navigation, soft backgrounds, program-card structure and footer approach are retained. The six program cards remain placeholders for layout review; they do not represent a confirmed program count or approved program details.

Design principle: refine the experience, don’t redesign the brand. These improvements establish a repeatable pattern that can be applied to other pages only where it supports the existing layout and content.

How this can guide the rest of the website

  1. Use a shared alignment systemKeep the logo, page headings and primary content aligned to a consistent container, with predictable spacing across breakpoints.
  2. Standardise interactive statesReuse the same button treatments, focus indicators, hover feedback and dropdown behaviour instead of styling each page independently.
  3. Keep mobile navigation predictableApply the same menu layout and tap-friendly spacing throughout the site so visitors do not need to relearn the interface on each page.
  4. Preserve page-specific needsCarry over the visual system, but let each page’s content determine its layout. Consistency should not mean forcing every section into identical cards.

Current status

Wireframe refinement complete

This version communicates the intended structure and interaction direction. The next stage is to confirm the final program information, replace placeholders with approved content and imagery, then integrate the page into the live site and test it across real devices and browsers.
