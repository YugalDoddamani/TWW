# The Wellness Workshop — Programs Page

A responsive concept for the Programs page of [The Wellness Workshop](https://www.wellnessworkshop.in/).

This project explores how the existing website's layout and visual identity can be carried into a clearer, more consistent Programs page. It is a design and review preview, not a replacement for the live website.

## Goals

- Present programs in a clear, easy-to-scan card layout.
- Keep the existing brand identity, colour palette, logo, and overall feel.
- Improve header alignment: logo on the left, navigation centred, and the main contact action on the right.
- Make navigation and program enquiries comfortable to use on mobile.
- Add restrained hover states, button feedback, and subtle shadows without overhauling the design.
- Establish reusable spacing, alignment, and interaction patterns that can be applied to other pages.

## Current design direction

- **Header:** left-aligned logo, centred desktop navigation, and a cleaner mobile menu.
- **Programs:** consistent cards with space for program imagery, description, duration, format, inclusions, pricing, and an enquiry action.
- **Interactions:** subtle card and button transitions, visible focus states, and reduced-motion support.
- **Responsive behaviour:** layouts and navigation adapt to smaller screens.
- **Brand continuity:** the goal is to refine consistency, not redesign the website from scratch.

## Placeholder content

Program details and card content are placeholders for review. They should not be treated as the final program catalogue, confirmed prices, or approved copy. Replace them with client-approved information and imagery before launch.
