# The Wellness Workshop — Programs Concept 01, Version 03

This is a focused refinement of Version 02. It keeps the wireframe placeholders and page structure.

## Files
- `index.html` — header elements reordered so the logo is left-aligned, navigation is centred on desktop, and the contact action is on the right.
- `styles.css` — Version 03 overrides appended at the end. Existing design rules remain intact.
- `script.js` — retained from Version 02; accessible menu behaviour, Escape handling, breakpoint reset, cursor enhancement, and button ripple remain in place.

## Apply to your existing folder
1. Back up your current `index.html` and `styles.css`.
2. Replace those files with the versions in this folder.
3. Keep your existing `script.js` (the included copy is unchanged).
4. Keep your existing `assets/` folder intact. The HTML still references `assets/logo.svg` and the existing page image paths.
5. Open `index.html` and test at desktop, tablet, and narrow mobile widths.

## What changed
- Desktop header: logo at the left edge of the content container, navigation visually centred, contact CTA aligned right.
- Mobile header: logo on the left, compact contact action and refined hamburger on the right.
- Mobile navigation: opens in a rounded, lightly shadowed panel rather than expanding the header into a full extra row.
- Micro-interactions: lighter button shadows, gentle button lift/press feedback, nav underline motion, refined wireframe card hover, and a small tools dropdown entrance.
- Reduced-motion preferences continue to be respected.
- Wireframe placeholders, card count, page copy, footer and FAQ structure are unchanged.

This remains a design preview. Verify contact details and final links with the client before publishing.
